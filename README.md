# Lokniti — India’s Political Strategy House

A premium concept website for an India-centric political consulting agency. Inspired by the content architecture of [indianpac.com](https://www.indianpac.com) (story, services, campaigns, youth pipeline, footprint) but fully original in brand, copy, and visual system.

## Open it

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## What is original

- Brand: **Lokniti** (not I-PAC)
- Visual system: navy / saffron / gold / cream, serif display type
- Campaign names are composite illustrations, not client reproductions
- Generated documentary-style photography
